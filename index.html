At home: Host

  1. Plug the capture card into the computer.
  2. Open EZTV and tap Host.
  3. Follow steps 1 to 3 and keep the tab open.

Anywhere: Watch

  1. Open the link the host sent you, or type their 6-letter code.
  2. Tap Join. EZTV reconnects by itself if you leave and come back.
  3. Watch full screen and use the remote.

Video goes straight from the host to you. A small free service only introduces your devices to each other. No account, no uploads.

    Help & troubleshooting

    Keep playing when I leave the site
    • Leave Sound on. Audio keeps playing in the background and shows lock-screen controls.
    • If the connection drops while you're away, EZTV rejoins by itself when you come back, or when your signal returns. You don't need to type the code again.
    • iPhone: tap Share → Add to Home Screen and open EZTV from the icon. This is the most reliable way to keep audio going. iOS may pause video while the app is hidden, but audio and the connection should continue.
    • Android: use Chrome and install from ⋮ → Add to Home screen. Tap Pop out for a floating video window.
    • Phones can still close a page in the background to save battery. If that happens, reopen EZTV and it reconnects to the last host.
    Setting up the UFO-R6
    • Add the UFO-R6 to the Smart Life / Tuya Smart app first, on the same Wi-Fi as the host computer.
    • On the host computer run pip install --upgrade tinytuya, then python -m tinytuya wizard to get your Device ID and Local Key.
    • Run python bridge.py and enter those once. Open EZTV from http://localhost:8787 or your normal link.
    • In Host step 3, tap Check connection, then Learn essential buttons.
    • Place the UFO-R6 where it can see the VSeeBox's IR window.
    Full screen
    • Tap Full screen. The bar hides itself; tap the screen to bring it back. Remote slides the remote over the video.
    • iPhone: Safari can't make a page truly full screen, so EZTV fills the display. Rotate to landscape for a bigger picture.
    My capture card isn't in the list
    • Tap Refresh devices and allow camera and microphone access.
    • Close OBS, Zoom, Teams or other tabs using the card.
    • Try another USB port (blue USB 3 works best) and replug the card.
    • Cards usually show as "USB Video", "HDMI Capture" or "UVC Camera".
    The picture is black or there is no sound
    • Make sure the VSeeBox is on and its HDMI goes into the capture card's IN port.
    • Some apps use copy protection (HDCP) which capture cards can't record. Live channels usually work.
    • On the host, pick the card's audio (often "USB Digital Audio"). The level bar should move.
    • On the viewer, tap Sound if it shows off.
    The viewer can't connect
    • Keep the host tab open and check the code is typed right.
    • Turn off VPN or privacy extensions on both devices, then reload.
    • If a code stops working, tap New code on the host.
    Remote buttons do nothing
    • Make sure bridge.py is running and Host step 3 says Connected.
    • Each button must be learned once. Learned buttons show a green outline under "Learn or re-learn any button".
    • Move the UFO-R6 closer to the VSeeBox, and re-learn a button if it is unreliable.
    EZTV runs entirely in your browser. No accounts, no uploads.

    Setup guide

    Do these in order. Tick each box when done and EZTV remembers where you are. The whole thing takes about 20 minutes, once.

    What connects to what
    VSeeBoxHDMI cable →Capture card (IN)
    Capture cardUSB →Computer (the host)
    Capture card (OUT)HDMI →TV (optional)
    UFO-R6sits in front of VSeeBoxinfrared →VSeeBox
    bridge.pyis a program on the computer. It talks to the UFO-R6 over Wi-Fi.
    1Plug in the hardware
    1. Connect the VSeeBox HDMI out to the IN port of your capture card.
    2. Plug the capture card's USB into the computer (a blue USB 3 port is best).
    3. Optional: connect the capture card's OUT port to your TV so you can still watch on it.
    4. Power the UFO-R6 with its USB cable and put it close to the VSeeBox, pointing at the front of the box where its infrared window is. A few inches to a few feet away works.
    There is nothing to physically connect for the bridge. It is just a small program that runs on your computer.
    2Put the UFO-R6 on your Wi-Fi
    1. Install the Smart Life (or Tuya Smart) app on your phone and create an account.
    2. Make sure your phone is on your 2.4 GHz Wi-Fi. Most smart devices don't join 5 GHz.
    3. In the app tap + → Add device. If the UFO-R6 doesn't appear, hold its reset button until the light blinks fast, then try again.
    4. Follow the app until it says the device was added.
    Your computer must be on the same home Wi-Fi network as the UFO-R6.
    3Install Python and the helper (computer)
    1. Go to python.org/downloads and install Python. On Windows, tick "Add Python to PATH" on the first screen.
    2. Open a terminal. Windows: press the Windows key, type cmd, Enter. Mac: open Terminal.
    3. Paste this and press Enter:
    pip install --upgrade tinytuya
    If "pip" isn't found on Mac, use pip3 and python3 everywhere instead.
    4Get your UFO-R6 Device ID and Local Key

    The Local Key is a password your computer needs to talk to the UFO-R6. It is free to get:

    1. Create a free account at iot.tuya.com and choose Cloud → Create Cloud Project. Pick the data center for your country.
    2. In the project, open Devices → Link App Account, scan the QR code with the Smart Life app, and link it.
    3. Note the project's Access ID and Access Secret from its overview page.
    4. In the terminal run:
    python -m tinytuya wizard
    1. Enter the Access ID, Access Secret and one Device ID when asked (in the Smart Life app: open the UFO-R6 → ✎ → Device Information). Choose your region.
    2. It prints your devices. Write down the Device ID and Local Key next to the UFO-R6.
    Tuya changes its website now and then. If a menu name is slightly different, look for the same idea: a cloud project linked to your app account.
    5Put the files in one folder and start the bridge
    1. Create a folder, for example EZTV, and put these files in it: index.html, bridge.py, icon-192.png, icon-512.png, apple-touch-icon.png, manifest.webmanifest.
    2. In the terminal, go to that folder. Example:
    cd Desktop/EZTV
    1. Start the bridge:
    python bridge.py
    1. The first time it asks for your Device ID, Local Key and the UFO-R6's IP address (press Enter to find it automatically). It saves them, so it only asks once.
    2. When it says "EZTV Bridge running", leave that window open. Closing it stops the remote.
    6Open EZTV on the computer and start the picture
    1. In the browser on the host computer open http://localhost:8787.
    2. Tap Host at the top. Allow camera and microphone when asked.
    3. Step 1: pick your capture card (and its sound if listed), then tap Start capture. You should see the VSeeBox picture.
    4. Step 2 shows your code. Leave this tab open while you want to watch.
    7Teach EZTV your VSeeBox remote buttons
    1. In Host step 3, tap Check connection. It should say connected to the UFO-R6.
    2. Tap Learn essential buttons.
    3. When the popup asks for a button, point the VSeeBox's own remote at the UFO-R6, about 10 cm away, and press that button once.
    4. Repeat for each button it asks for. You can learn the number keys and others later under "Learn or re-learn any button".
    5. Tap Send test press. The VSeeBox should react.
    8Watch on your phone
    1. On the host tap Copy link (or note the 6-letter code) and send it to your phone.
    2. On the phone open the link, or open EZTV and type the code, then tap Join.
    3. Tap Full screen and use Remote for the buttons.
    4. Phone tip: iPhone Share → Add to Home Screen. Android Chrome ⋮ → Add to Home screen.
    To watch away from home, the host computer must stay on, awake, with the EZTV tab open. Also publish EZTV to a public link (for example GitHub Pages), then paste that link in Settings → Public EZTV link. Both phone and computer need the same page address style (https).
    ?Something isn't working
    • "Can't reach the bridge": the terminal window with bridge.py must be open. Check the Bridge address is http://127.0.0.1:8787.
    • "Can't reach the UFO-R6": wrong Device ID or Local Key, or different Wi-Fi. Delete bridge.json and run bridge.py again to re-enter them.
    • Button learned but nothing happens: move the UFO-R6 closer to the VSeeBox's front, re-learn the button.
    • No picture: close OBS, Zoom or other apps using the capture card, then Refresh devices.
    • Viewer can't join: keep the host tab open, turn off VPNs, or tap New code.
